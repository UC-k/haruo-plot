# haruo-plot
branch
関数を入力してグラフを描画する、依存関係なしの関数グラフアプリです。

## 起動

ブラウザで `index.html` を開くか、リポジトリ直下で次を実行します。

```sh
python3 -m http.server 8000
```

その後、http://localhost:8000/ を開いてください。

## 機能

- `x` を使った関数式の入力と描画
- `y=5x`、`2(x+1)`、`2sin(x)` のような暗黙の乗算を自動認識
- `sin`, `cos`, `tan`, `sqrt`, `abs`, `log`, `exp` などの基本関数
- x/y表示範囲の編集
- 複数関数の重ね描き、関数ごとの色分け、個別削除
- マウスホイールによるズームと、ドラッグによる表示範囲の移動
- フィボナッチ数列をもとにした生成BGM（Web Audio API）
