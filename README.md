# haruo-plot

関数を入力してグラフを描画する、依存関係なしの小さなMVPです。

## 起動

ブラウザで `index.html` を開くか、リポジトリ直下で次を実行します。

```sh
python3 -m http.server 8000
```

その後、http://localhost:8000/ を開いてください。

## MVPの範囲

- `x` を使った関数式の入力と描画
- `sin`, `cos`, `tan`, `sqrt`, `abs`, `log`, `exp` などの基本関数
- x/y表示範囲の編集
- マウスホイールによるズーム

次の段階では、複数関数、ドラッグによるパン、式ごとの色、URLへの状態保存、スマートフォン操作を追加できます。
